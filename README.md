# 晾一晾 · 桌面整理

一个本地运行的 Windows 桌面整理应用。启动后，透明衣绳直接显示在 Windows 桌面上，不再先打开普通软件窗口。九类文件夹可以在桌面上点击、浏览和整理。衣绳与文件夹会持续轻轻摇摆，每隔一段时间自动吹起一阵风；悬停文件夹或点击「吹一阵风」也会触发动效。

衣绳会同时显示个人桌面和公用桌面的内容。运行期间，Windows 原生桌面图标会暂时隐藏；正常退出时自动恢复。公用桌面的快捷方式只在衣绳中分类显示，不会被移动，因此不会改变其他账户的桌面。若程序意外退出，可重新启动，再从托盘正常退出以恢复图标。

## 启动

在本机双击 **启动晾一晾.cmd**。程序会直接把分类衣绳显示在桌面顶部；点击衣绳右侧的「管理面板」可打开完整管理窗口，点击「回到桌面」可将其隐藏。右下角系统托盘的「晾一晾」图标提供管理面板、刷新和退出入口。

衣绳占据桌面顶部约 410 像素的鼠标区域；其下方仍可操作 Windows 桌面。打开分类列表时，桌面窗口会暂时向下展开，关闭列表后收回。

首次安装或迁移到另一台电脑时，先安装 [Node.js](https://nodejs.org/) 并在本目录运行 `npm install`，然后运行 `npm start` 或双击启动脚本。桌面挂载依赖 Windows Explorer；若 Explorer 无法提供桌面宿主，程序会自动退回管理窗口并说明原因。

## 使用

1. 默认扫描 Windows 桌面；桌面衣绳会显示每类文件的数量，点击分类卡片查看文件。
2. 点击桌面顶部的「整理桌面」后，个人桌面待整理文件会移动到桌面的 `晾一晾-已整理`，再按文档、图片、视频、音乐、压缩文件、安装程序、快捷方式、原有文件夹和其他文件分开。公用桌面项目不会移动。
3. 双击弹出列表里的文件可以打开它；「撤销」会把上次移动的文件放回原处。尚无整理记录时点击「撤销」，衣绳会说明原因。如果原处已出现同名文件，应用会保留两份，不会覆盖。
4. 「管理面板」提供更详细的待整理列表，也可以在面板里切换要扫描的文件夹。

应用不会上传文件。正在运行的应用目录会被排除在扫描和整理之外。请先查看待整理列表，再点击整理；整理会实际移动文件，桌面快捷方式也会移入分类目录。
